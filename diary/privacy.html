일기 노트 개인정보 처리방침

시행일 2026년 10월 27일 · 만든 곳 Blog J(luvbong.tistory.com)

Google 로그인 창에는 앱 이름이 「Blog J 무료 도구」로 표시됩니다(Blog J의 레시피 노트 · 스크랩 노트 · 여행 노트 · 일기 노트가 함께 쓰는 이름). 공통 처리방침 보기

1. 모으는 정보

일기 노트는 회원 가입이 없고, 만든 사람의 서버로 어떤 정보도 보내지 않습니다.
일기 · 일정 · 사진 · 스티커는 모두 사용하는 기기(브라우저 저장소)와, 사용자가 고른 저장 위치(내 PC 폴더 또는 내 구글 드라이브)에만 저장됩니다.

2. 구글 드라이브 연동

  • 사용자가 「구글 드라이브 연결」을 누른 경우에만 Google 로그인 창이 열립니다.
  • 요청하는 권한은 drive.file 하나입니다. 이 앱이 직접 만든 파일(내 드라이브의 「일기노트」 폴더)만 읽고 쓸 수 있으며, 드라이브의 다른 파일은 볼 수 없습니다.
  • 연결한 계정의 이메일 주소는 다시 로그인할 때 같은 계정을 고르기 위해 사용자 기기 안에만 저장합니다.
  • Google 사용자 데이터는 일기를 기기 사이에서 맞추는 일에만 쓰며, 다른 사람에게 주거나 팔거나 광고에 쓰지 않습니다.
  • 일기 노트가 Google API로 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.
  • 설정의 「연결 끊기」로 언제든 연동을 멈출 수 있습니다. Google 계정의 「보안 › 서드 파티 앱 액세스」에서 권한을 거둘 수도 있습니다.

3. 외부로 나가는 통신

  • 구글 드라이브 연동을 켠 경우: Google 로그인 · Google Drive API 통신
  • 새 버전 확인: GitHub Pages의 버전 정보 파일을 읽기만 합니다(아무것도 보내지 않음).
  • 「지도」 · 「길안내」를 누를 때: 그 일정의 장소 이름(또는 넣은 위치 좌표)을 고른 지도 앱(네이버 지도 · 카카오맵 · 티맵 · 구글 지도)에 검색어로 넘깁니다. 누르기 전에는 아무것도 보내지 않습니다.
  • 사진: 고른 사진의 찍은 시간만 읽어 일정에 나누고, 줄인 사본만 저장합니다(위치 정보는 쓰지 않음).

4. 지우기

기기의 데이터는 브라우저의 사이트 데이터 삭제로, 드라이브의 데이터는 「일기노트」 폴더를 지우는 것으로 모두 없앨 수 있습니다.
